# Sanika Deokar — White & Sky Blue Portfolio

Responsive React + Vite portfolio with a clean white canvas, sky-blue accents, smooth transitions, and scroll-reveal animations.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL Vite prints, usually `http://localhost:5173`.

## Production build
```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. In Vercel, choose Add New → Project and import the repository.
3. Use build command `npm run build` and output directory `dist`.
4. Click Deploy.

## Before publishing
Confirm project and internship descriptions, add real repository/demo links for projects where available, and add a resume PDF if you want a download button. The source has not been browser-tested in this workspace.
